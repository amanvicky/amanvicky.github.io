the problem

Founders and analysts pay a lot for venture due diligence, and the AI tools that promise it tend to hallucinate: confident answers, no sources. I wanted the opposite — an agent team where every claim carries the link it came from, and where the final output isn't a vibe but a decision.

what it does

Feed it a company (Stripe, Razorpay, your competitor) or a rough idea. Thirteen agents research and argue, then the app returns a 14-tab dossier:

  • business model viability and structural verdict
  • compliance traps, per country and state
  • why similar companies died, and real revenue from SEC filings
  • editable pricing math, burn and breakeven
  • user complaints, free distribution channels, starter code
  • a red-team panel that argues with your plan
  • a chat panel that answers follow-ups using your own numbers
  • a verdict protocol that forces a GO or NO-GO so the dossier actually ends

No API keys, no accounts. Nothing leaves your machine.

how it's built

FastAPI on the back, Next.js on the front, one Python entry point that hides all of it:

$ python genesis.py            # installs venv + deps, builds, runs in background
$ python genesis.py status     # what's running
$ python genesis.py logs api   # tail logs
$ python genesis.py doctor     # pre-flight check
$ python genesis.py stop       # shut it down
$ python genesis.py uninstall  # stop + clean up (--deep removes venv too)

A watchdog restarts crashed services, there's an optional Tor mode for anonymous research (--no-tor to skip it), and CI runs the test suite on every push. v1.1.0 is tagged and released.

proof, not promises

The repo ships proofs/capture.mjs: one command regenerates all 14 screenshots below from the running app. If a future change breaks the UI, the proofs break with it.
